# Generated Worksheets

This directory contains automatically generated practice worksheets for students.

Worksheets are generated based on student performance metrics and prioritized by:
- Frequency of mistakes
- Exam weight (IB HL AA Math)
- Recency of mistakes
- Time since last worksheet

## File Naming

Format: `worksheet_{student_id}_{category_id}_{timestamp}.html`

Example: `worksheet_12345_CAT001_20240115_143022.html`
